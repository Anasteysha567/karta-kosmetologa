# Карта косметолога — браузерная тестовая версия

Публичная демонстрационная версия приложения для проверки интерфейса на компьютере и телефоне.

- вход через ChatGPT или GitHub посетителям не требуется;
- тестовые записи хранятся только в `localStorage` конкретного браузера;
- данные разных устройств не синхронизируются;
- реальные персональные и медицинские данные использовать нельзя;
- для голосового ввода браузер может запросить разрешение на микрофон.

Исходный Android-проект, модель офлайн-распознавания и ключ подписи в этот публичный репозиторий не входят.
